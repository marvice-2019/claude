10:15 · Standup

Team setup in 5 steps.

  1. 10:15

    Install at least one agent CLI

    Claude Code is our standard. Use the native installer on macOS and Linux; it doesn't need Node. If a CLI is missing, the app also shows an Install card in the agent's terminal.

    curl -fsSL https://claude.ai/install.sh | bash
    • No sudo. It installs into your home folder, and the installer refuses to run under sudo.
    • Open a new Terminal window, then run claude --version. If you get "command not found", add it to your PATH (it installs to ~/.local/bin): 
      echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc && source ~/.zshrc
    • Installed with npm before? Remove that copy so the app doesn't pick up an old one: 
      npm uninstall -g @anthropic-ai/claude-code
  2. 10:20

    Sign in with your Marvice seat

    Sign in inside the app's terminal with the account Marvice assigned you. Agents run on that plan's hourly limits, so don't use personal accounts for client work.

  3. 10:25

    Run the onboarding wizard

    First launch walks you through it. When it's done, you land on the floor and the orchestrator takes the corner office automatically.

  4. 10:30

    Give every agent its own folder

    Use Add agent and point each one at a single repo or client folder. One agent per job keeps context small and output reviewable.

  5. 10:35

    Check prerequisites

    Settings → Prerequisites lists anything still missing. Local models and your own API keys go in Settings → AI Engines.

11:00 · House rules

Four rules for the floor.

Credentials stay out of prompts

Never paste client passwords, API secrets or payment details into an agent. Use environment variables and .env files that are git-ignored.

A human reviews before anything ships

Agents open branches and PRs. They don't push to main, deploy, or send client-facing messages without a person approving.

One client per agent

Don't mix client workspaces in one agent's folder or memory. It prevents data crossing between accounts.

Stuck? Ask in the team channel

Post the agent's terminal output and the step you're on. Most install issues are a missing CLI or an expired sign-in.

14:00 · Something broke

Troubleshooting.

The problems the team has hit so far, and how to fix each one in a couple of minutes.

Agents show CRASHED · exit 1

The claude CLI behind the agents failed to start, so no agent is running. Check these in a normal terminal, in order:

  1. Is it installed? claude --version should print a version. If not: 
    curl -fsSL https://claude.ai/install.sh | bash
    No sudo; open a new Terminal window afterwards. Still "command not found", or an old npm copy around? See the install tips.
  2. Is it signed in? Run claude, type /login, and sign in with your Marvice seat.
  3. Is it current? Agents set to a newer model need a recent CLI: 
    claude update
  4. Restart the agents from the floor. Still crashing? Paste the last lines of the agent's terminal in the team channel.
Skills → install shows HTTP 403

The Skills tab downloads through GitHub's API without signing in. GitHub allows 60 of those requests per hour per IP, and the whole office shares one IP, so a few installs use up the hour. Nothing is wrong with your setup.

  1. OBRA skills (finishing-a-development-branch, preserving-productive-tensions and the rest): install the whole set as a plugin instead. Run claude, then: 
    /plugin marketplace add obra/superpowers-marketplace
/plugin install superpowers@superpowers-marketplace
  2. Other publishers: wait an hour and install one or two at a time, or copy by hand: git clone the repo and put the skill's folder in ~/.claude/skills/.
Settings → Prerequisites shows 2 of 16 ready

Don't worry about the count: 12 of the 16 rows are optional agent engines (Codex, Grok, Qwen and so on). Only four matter: uv, MemPalace, git and Claude Code. Node.js is optional; the app installs it when an engine needs it. Skip "ask … to set up everything" if your agents are crashing, since that agent can't run either. Paste these in Terminal (macOS/Linux) one at a time:

# 1. uv, the Python toolchain MemPalace needs
curl -LsSf https://astral.sh/uv/install.sh | sh
source $HOME/.local/bin/env

# 2. MemPalace, semantic memory for agents
uv tool install mempalace

# 3. git, if it isn't READY (macOS)
xcode-select --install

# 4. Claude Code (native, no Node needed), then sign in
curl -fsSL https://claude.ai/install.sh | bash
claude --version
claude          # type /login, sign in with your Marvice seat, then /exit
  1. Quit Munder Difflin fully and reopen it. It only detects new tools on launch.
  2. Settings → Prerequisites → re-check. The four essentials should read READY.
  3. Restart the agents from the floor. Windows users: the matching PowerShell commands are under each row in Prerequisites.

16:30 · Questions

Before you ask.

What is Munder Difflin?

An open-source desktop app (MIT) that wraps terminal coding CLIs as agents, gives each one memory and a mailbox, and puts an orchestrator in charge. Dots is Marvice's guide to running it as a team.

Does it work with my Claude Code seat?

Yes. It runs the real claude CLI, so it uses your existing sign-in and that plan's hourly limits. No separate API billing is needed.

Does our code leave my laptop?

The app, its memory and the agents' folders all stay on your machine. Each CLI still sends prompts and code context to its own provider, exactly as it does when you run it in a normal terminal.

Does my laptop need to stay on?

Yes. Agents are processes on your machine, so they pause when it sleeps or the app closes.

Is it free?

The app is free and open source. HarnessMD sells an optional Pro plan; check with ops before buying a seat.

Can I run agents on more than one project at once?

Yes. Give each agent its own folder. Keep to one client per agent (house rule 3).
