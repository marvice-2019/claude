# ConXyou Diwali 2026 corporate gifting catalogue

4-page A4 catalogue (cover, how ordering works + deadline, three gift tiers, add-ons + contact).

- `conxyou-diwali-2026-catalogue.pdf`: ready to send **once the highlighted yellow fields are filled**
  (minimum order for each tier, order cut-off and delivery dates). Prices come from https://conxyou.com/conxyou-priced-catalogue-2026/ (excl. 18% GST).
- `conxyou-diwali-2026-catalogue.html`: same file with fonts embedded; open in Chrome → Print → Save as PDF.
- `catalogue.src.html`: editable source (fonts are injected at build time).

Tiers map to real catalogue categories: Deepam = small / notebook gift sets (₹205–879), Utsav = executive / bottle / drinkware sets (₹739–3,449), Lakshmi = premium hampers / tech & eco sets (₹1,749–5,199).
